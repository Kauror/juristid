Deliberately narrower than the administrative browse at /haldus/arvamuste-arhiiv/, which shares its search function. There a reviewer decides whose letter this is; here a lawyer finds out what the Chamber wrote about a subject. So no candidate state, no link form, no withdraw action, and no shortcut into the reconciliation queue. **No row ever names a Matter.** Not because these rows lack the foreign key — they have it — but because naming the Matter would make the archive a route into the register: a reader could learn the title and reference of a RESTRICTED entry from a letter tied to it. The linked/unlinked state is a fact about the letter and is safe to show; the identity of what it is linked to is not, and the detail page resolves it through `Matter.objects.visible_to` before it says anything (docs/adr/0028). The heading strip keeps four figures apart on purpose. Held is not filed onto a Matter, filed is not sent as an opinion, and only a canonical Submission is a claim that Koda sent anything at all. {% endcomment %} {% block workspace_context %} {{ counts.total }} kirja · {{ counts.linked }} teemaga seotud · {{ counts.with_submission }} kanoonilise arvamusena {% endblock %} {% block workspace %}
