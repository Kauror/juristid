{% extends "base.html" %} {% comment %} The Arvamused shell: one heading, one tab strip, two very different lists. The tab strip is the whole design decision. Canonical Submissions and the historical archive answer the same human question — "what did we write about this" — from sources that are not interchangeable, and the one thing this workspace must never do is let a reader mistake one for the other. Merging them into a single list with a badge would put a held PDF and a recorded outbound act on the same row, and the badge would be the only thing standing between a lawyer and a wrong count. So the sources stay in separate tabs, each captioned with what it is, and the workspace has no code that would need unpicking when P4 eventually turns defensible archive letters into real Submissions — those simply start appearing under Saadetud on their own. Arhiivikirjad appears only for a reader `may_read_archive` admits. It is captioned rather than silently dropped for everybody else: hiding it entirely would say "there is no archive", which is untrue, and a lawyer who has heard about the 767 letters would reasonably think the feature was broken. {% endcomment %} {% block content %}
