{% comment %} A GET form around the search box, so pressing Enter still works and the page is usable with JavaScript switched off entirely. HTMX only makes the same request earlier (brief 7). `hx-trigger` carries `changed`, which is what stops a request firing for an arrow key or a repeated value; the 250 ms delay is inside the 200–350 window the brief asks for. `hx-push-url` writes the address the answer came from, so refresh, Back, Forward and a pasted link all agree. **No `search` trigger.** Chromium fires the box's `search` event on Enter as well as the form's `submit`, so listening to both sent every Enter twice and pushed the same address twice — the first Back went nowhere (2026-10-23 bug-bounty, B-04). `submit` is Enter and `Otsi`; the clear button and Escape in the box fire `input` too, so clearing still answers.
