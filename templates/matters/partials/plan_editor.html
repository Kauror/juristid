{% comment %} `Muuda plaani` — the whole plan, skipped steps included, and what may change. Similar in spirit to `Muuda kulgu` and nothing like a workflow builder (docs/adr/0133 §10). Each row says what the step is and which state it is in, and offers only the acts that state allows: * a step still ahead — `↑` / `↓` among the steps still ahead, `Muuda` (its words and linked operation), `Jäta vahele`; * the current step — nothing here: it changes through `Muuda` beside it, and leaves the plan by being finished or replaced; * a finished step — `Korda`, which adds a new occurrence; the finished one is history and is not edited; * a skipped step — `Taasta`. **Buttons, not dragging**, so the order changes the same way with a keyboard, a pointer and a screen reader; each button's accessible name says which step it moves. Every form posts the plan revision it was drawn from, and a plan somebody has changed since refuses rather than being overwritten. {% endcomment %}
