{% comment %} «Nihuta kuupäeva» — one internal task's day moved by a day, a week or a month (app/matters/date_shift.py, docs/adr/0143 amendment of 2026-10-26). Choosing a move only previews it: the three proposed days are computed on the server from the stored day and the chosen one is shown under the choices (CSS `:has`, no script). Nothing is written until `Salvesta`, and the server recomputes the day itself and refuses if the step or its day changed since this was drawn (`kuupaev`, `uus_`). `tagasi` is this page's own address, so the save lands back on the same timeline horizon and calendar period; the server follows it only to Minu asjad or a colleague's desk. Used in a work row's `⋯` menu and in the calendar's event details — the same form and the same server operation from both. {% endcomment %}
