{% comment %} `Teema käik` — the horizontal process strip, first thing inside the `Ajajoon` body and above the chronology. You see which major procedural acts a file has been through before you scroll anything (TEEMA_TARGET_SPEC §D). **Five labels and no more:** `Alustatud`, `Koja arvamus`, `Arvamuse tähtaeg`, `Jõustumine`, `Lõpetatud`. One grammar, and it is the one this strip has always had: a filled accent dot with an accent connector running to the next column, and `:last-child` drawing none — so the line ends at the rightmost dot. A milestone that is still ahead — a response deadline, a commencement — is drawn exactly like one behind us, because the strip states dated points and not elapsed ones. It carries **no** `praegu` and no `N p`: where the file stands *now* is `Hetkeseis` in the header, which is the one place that is stated, and a countdown here would be this component judging an urgency nobody asked it for. **Only the milestones this Matter actually has.** `app/matters/process_timeline.py` derives the columns from canonical records and returns nothing at all for a Matter that has none. A native Matter with no deadline and no sent opinion draws one dot and no connector; give it a response deadline and it reads `Alustatud · Arvamuse tähtaeg`, which is a known beginning and a known destination.
