Membership, sources and ordering are untouched by the 2026-09-12 amendment; what changed is how time is drawn. **Reached, today, ahead.** A column behind us keeps the filled accent dot and the accent rail; a column still ahead is muted, and one dated today is ringed. The connector is a two-colour rail rather than a flat one — accent as far as today has come inside that segment, muted the rest of the way — so a file whose deadline is a fortnight off shows the boundary sitting between the two columns instead of implying the deadline has passed. `:last-child` still draws no connector, so the rail still ends at the rightmost dot. The *words* are exactly what they were. No `praegu`, no `N p`, no countdown and no column marked as the step the file is standing on: where it stands now is `Hetkeseis` in the header, and a countdown here would be this component judging an urgency nobody asked it for. Colour is not the only signal either — a column dated today carries `aria-current="date"` and one still ahead says «Tulevikus» to a screen reader, because a strip that reads as five identical milestones with the stylesheet off is the same defect this amendment exists to fix (docs/adr/0074 §12.2, amended 2026-09-12). **Only the milestones this Matter actually has.** `app/matters/process_timeline.py` derives the columns from canonical records and returns nothing at all for a Matter that has none. A native Matter with no deadline and no sent opinion draws one dot and no connector; give it a response deadline and it reads `Alustatud · Arvamuse tähtaeg`, which is a known beginning and a known destination.
