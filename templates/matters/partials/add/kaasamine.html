{% comment %} `+ Kaasamine` — start a consultation round, or add what came back. **Who was engaged and when, then — separately — what came back** (docs/adr/0142, below). The start form used to open on a row of `Liik` chips and a four-way `Täpsus` control, so the first two decisions a lawyer made were a classification nothing ever read back and a precision an as-it-happens round never needs. Both are gone: every row written here is `Muu` and an exact day, historical rows keep whatever they were given, and correcting one is `Muuda` on its chronology row (docs/adr/0086 §1). **`Kaasamise kuupäev` starts filled with today and clears.** Recording something that just happened is the usual case, and the default is visible in the box where it can be read, changed and emptied — which is the one shape docs/adr/0078 §2 allows a date default to take. **`Tagasisidet ootame kuni` is asked here again — optional and empty** (docs/adr/0120, UQ-10). Without it the fact that decides whether a round is waiting could only be given by saving the round and then opening `Muuda` on it. What docs/adr/0091 §2 objected to was a *pre-filled* box that opened a wait nobody had decided on; this one has no default, so a round recorded as a completed act opens no wait, draws no work item and stores no deadline. Filled in, it is the same column `Muuda` corrects and the same wait `Ootan tagasisidet` opens on the row: the single `WorkItem`, `PRAEGUNE TEGEVUS`, «Tagasiside tähtaeg» on the rail and `Lõpeta kaasamine`, all as docs/adr/0086 §3 and §6 built them. Any day is accepted — past, today or future. {% endcomment %} {% comment %} **Two acts, two forms** (docs/adr/0142): `Alusta kaasamist` records that the request went out; `Lisa tagasiside` records what came back from a round that is open. The same nested chip row `+ Lisa` and `+ Arvamus / tagasiside` use, so either can be chosen by hand. `kaasamine_choice` opens the one this Matter needs — `Lisa tagasiside` while a round is open, `Alusta kaasamist` otherwise — from the canonical open-round reading (`work_items.open_feedback_waits`), never from a deadline, a title or which round is newest. A refusal reopens the form it came from (`_workspace_choices`). {% endcomment %}
