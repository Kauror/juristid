{% comment %} `+ Kaasamine` — the three questions a consultation round actually has. **Who was engaged, when it happened, and what came back.** The panel used to open on a row of `Liik` chips and a four-way `Täpsus` control, so the first two decisions a lawyer made were a classification nothing ever read back and a precision an as-it-happens round never needs. Both are gone: every row written here is `Muu` and an exact day, historical rows keep whatever they were given, and correcting one is `Muuda` on its chronology row (docs/adr/0086 §1). **`Kaasamise kuupäev` starts filled with today and clears.** Recording something that just happened is the usual case, and the default is visible in the box where it can be read, changed and emptied — which is the one shape docs/adr/0078 §2 allows a date default to take. **`Tagasisidet ootame kuni` is not asked here at all, which is where docs/adr/0086 §2 finally lands.** That record put the box on this panel opening on today + 7, on an argument that was right about its own subject: a week is what a round asks for when nobody says otherwise. The first lawyer test showed the *consequence* was out of proportion to a default — recording «19.09 — kaasati 234 tööstusettevõtet» is a completed act, and under a pre-filled deadline it also opened a managed wait, drew a work item, appeared on somebody's Minu asjad and then needed a second deliberate act to get off the page. Emptying the default was the first answer and it was not enough: an empty box is still a box that has to be read, understood and skipped, every time, and it was still the panel that opened the wait. So the question moved out of the capture panel altogether (lawyer feedback 11, docs/adr/0091 §2). **The wait itself is unchanged and is not withdrawn.** It is `Ootan tagasisidet` on the round's own chronology row now — one named act, taken by somebody who has decided this file is waiting on an answer. The column, the single `WorkItem`, `PRAEGUNE TEGEVUS`, the overdue wording and `Lõpeta kaasamine` are all exactly as docs/adr/0086 §3 and §6 built them; it still creates no `Järgmiseks`, still is not `Arvamuse tähtaeg`, and still counts towards no deadline statistic. Every round already waiting goes on waiting (matters/partials/engagement_row.html). {% endcomment %}
