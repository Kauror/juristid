This file should be written up somewhere the public can read it — an overview for the membership on the Chamber's own site, or a news item somewhere else. **One activity and no type selector.** The record used to be `Kodulehe ülevaade` and could point only at koda.ee, which made the file unable to record the same write-up appearing in a trade paper or on a partner's site. It is neutral now, and it stays *one* control rather than growing a `liik` chip: an overview and a news item are the same act, and the address the row already carries is what tells a reader which they are looking at (docs/adr/0085 §1). **Two boxes, both answered, and one outcome.** This panel records a page that exists. docs/adr/0081 §1 gave it one button and no fields, because at the moment somebody decides a Matter should be written up there is no address and no date. docs/adr/0083 added the boxes as optional, so a lawyer recording a page already published did not have to file a plan and publish it from a second control. What that left was three answers, one of which — *neither box* — was reached by pressing `Salvesta` on a form that looked untouched. A save whose meaning depends on what somebody did not type is the one shape a composer may not have. So the address is required, the day opens on today, and a valid save is a publication (docs/adr/0095 §5). **`Plaanis` and `Tühistatud` are untouched.** Every stored plan still reads on the file, still carries `Avalda` and `Tühista` in `website_overviews.html`, and `plan_website_overview` still writes one. What is gone is a silent way to create one from this panel. An optional `Pealkiri` since docs/adr/0127 §1 (narrowing docs/adr/0081 §2), and still no description and no attachment. It is not a `+ Märge`, it is not a `+ Töövõit`, and it is not a deadline — a write-up that is owed makes no `NextAction`, no work item and no badge, so a Matter carrying one never reads as late (docs/adr/0081 §4). {% endcomment %}
