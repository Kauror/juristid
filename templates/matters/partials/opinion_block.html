The sent opinions are rows in the table above; listing them here as well would restore the duplication this change exists to remove (docs/adr/0060 §15). Three things live here, and each is either an action somebody owes or an action they may take: * **Koostamisel** — drafts. Only ever the ones that exist, and each shows the one step it is waiting for: a file, or the confirmation that it went out. * **Registreeri saatmine** — an opinion file on the record went out. Offered only where there is such a file with no canonical Submission, because otherwise there is nothing to register. * **Uus arvamus** — start a draft with no file yet. The Osakond figure «arvamust koostamisel» counts exactly these, so the way to make one is kept. Both forms are `
` rather than script-revealed panels: they work with the keyboard and without JavaScript, and they are closed until asked for. The block itself opens when a draft is waiting and is shut otherwise. Both forms are unbound — a refused write redirects with a message rather than re-rendering, which is how every full-page post in this application answers — so there is no error state here to open for. {% endcomment %}
