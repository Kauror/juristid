{% comment %} A searchable institution chooser: one text box that narrows one select. The real catalogue runs to hundreds of bodies. A select carrying all of them is unscannable and a wall of radio buttons is worse, so the list is fetched from the server for whatever was typed. No frontend library, no client-side store — HTMX swaps this same fragment back in, which is why the search box and the select live together in one file (Stage-2E.1 brief 13). Without JavaScript the select still holds the currently chosen body plus the first page of the catalogue, and the form still submits. The search box is an improvement on that, not a precondition for it. Rendered by the register's Täpsem otsing panel and re-rendered by `matters:organisation_choices`, so both paths produce identical markup. {% endcomment %}
