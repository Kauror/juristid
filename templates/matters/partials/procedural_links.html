{% comment %} `MENETLUSE LINGID` — where the official proceeding on this file actually lives. A rail card, because this is look-up material in the exact sense the rail was built for: nobody reads it, somebody reaches for it. The question it answers is the first one a lawyer asks when they open a file three months later — «kus see päriselt käib» — and the answer is an address they want to click, not a narrative they want to read (`rail.html`). **Nothing at all when there are none**, which is the ordinary case on a Matter nobody has recorded one for. There are no permanently visible empty sections on this page, and an empty table of five placeholder rows would be exactly the clutter this design removed the standing sections to be rid of. The one compact add affordance is the launcher's own `+ Menetluse link` chip, which is on every open Matter a writer can see (TEEMA_TARGET_SPEC §F, docs/adr/0074 §15). **A reference, and this page says so.** Nothing here is fetched, checked or watched, and the card claims nothing about whether the page is still up: a saved address is a record of what somebody stated on the day they stated it, and a dead link years later is a fact about the web rather than an error in this file (docs/adr/0089 §4). **The link is labelled, never printed.** `display_label` is the lawyer's own name for it, or the parsed host, or the kind — never the raw address, which is a line a reader has to parse instead of read and the one shape in which a look-alike address is believed. `target="_blank"`, `rel="noopener noreferrer"` and a visually hidden «— avaneb uues aknas» so the new tab is announced rather than merely happening (docs/adr/0081 §4, docs/adr/0085 §2). `Paranda` is gated on `can_write` alone and deliberately **not** on `matter.is_open`: an address recorded wrongly on a closed file must still be correctable, which is the same split `correct_website_overview_link` keeps (docs/adr/0081 §5, docs/adr/0089 §6). Adding one is the launcher's, which a closed Matter does not render at all. The card itself is gated on neither: a reader sees where the proceeding is, and no buttons that would refuse them. There is deliberately **no delete control**. A mistaken row is corrected, because what the file recorded and who recorded it is part of the file (docs/adr/0084 §8). {% endcomment %} {% if procedural_links %}
