{% comment %} `Koja seisukoht` — what the Chamber actually argued, in the reading flow. It used to be a tab. A lawyer opening a Matter had to navigate to find out whether Koda had a position at all, which is the second question anybody asks about a file. It is now read-first, inline-editable, and compact: text, a link to the sent opinion's own PDF where one exists, and nothing else (Teema redesign §19). Three states, deliberately different sizes: * a position exists — the text, the related opinion's date, the ★ PDF; * no text but an opinion went out — the file, because that *is* the position; * neither — one quiet line, not a card. An empty state that occupies a screen is what made the old page read as mostly missing data. {% endcomment %}
