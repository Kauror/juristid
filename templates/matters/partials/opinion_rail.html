{% comment %} `Koja arvamus`, in the facts rail — quick reference and nothing else. There is no separate `Koja seisukoht` concept in this product. The Chamber's output on a Matter is the opinion it sent, and an opinion is a file, so this block is the file. Each line is a direct authorized link to the exact current bytes; there is nothing else in it. **What used to be here and is not.** `+ Lisa arvamus` put an upload form in a 300px column beside the file list that already has one, and `Arvamused →` led to a per-Matter page that showed the same file a third time. Both are gone: opinions are managed on Dokumendid, where the Matter's files are, and this block is what a lawyer reaches for mid-sentence — the letter itself (docs/adr/0061). No version, no size, no checksum and no badge. Every one of those is a fact about the evidence rather than about the opinion, they all appear where evidence is stated, and none of them helps somebody who came here to open the letter. The files are the ones `app/submissions/opinions.py` returns: documents under `DocumentRole.KODA_SUBMISSION_FINAL`, **plus** the evidence bound to a `SENT` Submission on this Matter, deduplicated by document. Both, because the role alone was not the answer — `select_final_evidence` and `attach_final_evidence` handed an existing document bind the evidence without touching the classification, so a Matter could sit here saying `Arvamust ei ole lisatud` beside its own sent opinion (UX-005). A Matter may have several opinions and all of them are listed. There is no `Matter.final_opinion` and there is not going to be one: an initial opinion, a supplementary letter and a later joint submission are three files, and a single-valued shortcut could only ever name one of them. **Each line says which send it is** (UQ-28, docs/adr/0129 §9). Two opinions on one file were two bare filenames, often the same one, and nothing told them apart without opening both. So a letter that went out reads its day and who it went to above the link — «8.9.2026 · Justiits- ja Digiministeerium» — and «tagasi võetud» where it no longer stands. That is the send's own record, read through its own visibility; an opinion file no visible send accounts for reads as it always did. Its working documents, where it has any, follow as quieter links named `Töödokument`, so the editable file the lawyer reuses is one click away without the rail becoming a second file list. {% endcomment %}
