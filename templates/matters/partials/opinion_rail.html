{% comment %} `Koja arvamus`, in the facts rail. There is no separate `Koja seisukoht` concept in this product. The Chamber's output on a Matter is the opinion it sent, and an opinion is a file — so this block is the file, not a summary of it. The rail block that carried a free-text position, its `Seisukohta ei ole` line and its `Lisa seisukoht` link are gone. The files are `Document`s under `DocumentRole.KODA_SUBMISSION_FINAL`, which is already what every existing path writes: the closing flow, `select_final_evidence` on a Submission, and the opinion archive import. So an opinion uploaded here and one bound to a SENT Submission are the same row in the same list, and nothing is stored twice. Uploading goes through `documents:upload_evidence` — the one route that captures an immutable `DocumentVersion` — with the role fixed rather than chosen. It does not create a Submission: a file on the record is not a claim that anything was formally sent, and `mark_submission_sent` still owns that assertion together with its exact final evidence. `Arvamused` at the foot is the formal Submission workflow — recipients, channel, marking an opinion sent, withdrawing it. It is the link the retired position block used to carry, and it is the only way to that surface from a Matter. {% endcomment %}
