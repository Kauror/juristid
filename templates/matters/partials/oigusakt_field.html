{% load form_labels %} {% comment %} `Õigusakt` — what kind of instrument the file is about, on both pages that ask it. The third of the shared classification blocks, extracted for the reason the other two were: this markup already existed twice, and the two copies had already diverged — `Muuda teemat` put the free text in a row of its own below the fieldset while `Uus teema` revealed it inside, under the chips that open it (docs/adr/0096 §1). The master's shape wins, and the objection the edit page's copy was answering is answered by `other_instrument_open`: the box renders **open** whenever a `Muu` chip is ticked, server-side, so a stored `Õigusakti liik` is visible the moment the page opens and a refused save comes back with the box up and the refusal in it. Nothing is hidden behind a click. **Radios, one answer** (the owner's decision of 2026-10-09, docs/adr/0070's amendment of that date). The checkboxes, the `field__count` and the `chip__clear` went with the several answers they served; «Määramata» is a real chip, as on `Hetkeseis`, so the answer can be taken back. **A Matter that already holds several keeps them.** `Muuda teemat` then states them and offers «Jäta alles: …» first, chosen, so a save about anything else posts it and moves nothing; choosing one instrument, or «Määramata», is the deliberate correction (`held_legal_instruments`). `Muu` is a real vocabulary row here, unlike Valdkonnad's, so the template cannot tell it apart by field name and compares against the form instead — `in`, not `==`, because the reviewed vocabulary offers `Muu siseriiklik` and `Muu ELi dokument` and an older Matter may hold version 1.0's `Muu` (app/matters/forms.py `other_instrument_values`, docs/adr/0070). {% endcomment %}
