{% comment %} «Dokumendist leitud» — what the analyser read off this Matter's documents, with the evidence for every line. A panel above the edit form, not a second form. Nothing in it posts: a value reaches the record only by sitting in the form control below and being saved with the rest. Three treatments, and each is a word on the page rather than a colour: «vormil eeltäidetud» the GET put a HIGH-confidence value into an empty control; it is unsaved until Salvesta «Kasuta» a suggestion the person chooses; the button writes the value into the control (static/js/app.js) «juba valitud» the record already carries this value; the document agrees, and there is nothing to do Every line answers «kust see tuli?»: the file, the place in it (lk 1, kirja päis), OCR where the text was recognised rather than read, and a short excerpt. Excerpts are text and are escaped like any other text; no document content becomes markup here (docs/adr/0014, docs/adr/0060). {% endcomment %}
