{% extends "base.html" %} {% block title %}Ülevaade · {{ application_name }}{% endblock %} {% comment %} Ülevaade is the department's morning read, not a management dashboard. Every number is a count of rows that exist and links to the list behind it, so nothing here is a figure you have to take on trust. There is deliberately no ranking, no productivity measure and no response rate: a count of open files says nothing about effort, and presenting it as if it did is what the specification forbids (18.8). The one exception to "every number links" is the responsibility rail. It counts the register's own VASTUTAJA text while the register filters on the resolved owner, so a link would open a list that disagrees with the number above it — those rows are deliberately plain (docs/adr/0021, app/matters/dashboard.py). The tables use the register's fixed-layout discipline: named columns hold their width, the title takes what is left and clips, and a long Estonian title costs one line, never three. Full titles are on the Matter pages they link to. {% endcomment %} {% block content %}
