{% comment %} The theme switch (docs/adr/0147). One button, no menu: there are two themes, so the only choice is "the other one". The icon and the name say what pressing does, not what is on now — a sun offers the light theme, a moon offers the dark one. Both pairs are in the markup and the stylesheet shows one, chosen from `` (static/css/app.css). A hidden element is out of the accessibility tree as well as off the screen, so the spoken name changes with the icon and no script has to keep either in step. No `aria-pressed`: the name already changes with the state, and a toggle that did both would announce itself twice over. `type="button"`, so a press inside any form submits nothing. The click is handled by static/js/theme.js, which is also what reveals the button — without that script it would be a control that does nothing, so it is not shown at all. {% endcomment %}
