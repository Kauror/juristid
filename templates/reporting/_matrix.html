{% comment %} A two-dimensional count — year × responsibility, month × responsibility — as a real HTML table. Not a heat map. Every cell prints its number, the header cells carry `scope`, and the caption names the table. A grid whose value lived in a background shade would be unreadable to anybody who cannot separate two tints, and there would be no fallback: a heat map has no data table beneath it, it *is* the data table (master specification 17.8; Stage-2E brief 50, 81). Totals are printed, never computed here. Row totals, column totals and the grand total all arrive already worked out, so two renderings of the same matrix cannot add up differently (brief 54). The table sits inside `.tablewrap`, which scrolls horizontally on its own. A wide matrix must never push the page sideways. {% endcomment %}
