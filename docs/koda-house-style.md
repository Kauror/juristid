# Koda house style — how to name the Chamber in Estonian

The owner's guide (2026-11-23). It binds every AI writer in the app
(`app/register_watch/house_style.py`: `KODA_STYLE` in the prompt, `fix` on the
output, `manage.py fix_koda_style` for older rows) and is the reference for any
Estonian text written about the Chamber.

## Names

| Use | Form |
|---|---|
| Full official name | **Eesti Kaubandus-Tööstuskoda** (one hyphen, no spaces, `Tööstuskoda` one word) |
| Official English name | **Estonian Chamber of Commerce and Industry** (never without «and Industry») |
| Short, mid-sentence | **kaubanduskoda**, **koda** (lowercase) |
| Short, sentence or headline start | **Kaubanduskoda**, **Koda** |
| Abbreviation | **EKTK** — statutes, contracts, administrative papers; introduce the full name first; avoid in public texts |

Never «Eesti Kaubandus- ja Tööstuskoda», «Kaubandus Tööstuskoda», «kaubandus koda».

## Cases

| | Full name | Short |
|---|---|---|
| nimetav | Eesti Kaubandus-Tööstuskoda | kaubanduskoda / koda |
| omastav | Eesti Kaubandus-Tööstuskoja | kaubanduskoja / koja |
| alaleütlev | … Tööstuskojale | kaubanduskojale / kojale |
| seesütlev | … Tööstuskojas | kaubanduskojas / kojas |
| sisseütlev | … Tööstuskotta | kaubanduskotta / kotta |
| seestütlev | … Tööstuskojast | kaubanduskojast / kojast |
| kaasaütlev | … Tööstuskojaga | kaubanduskojaga / kojaga |

`Eesti` never changes; only the last part takes the ending. The genitive of
«koda» is «koja» — never «kaja».

## Functions, people, bodies

Lowercase: kaubanduskoja peadirektor, koja juhatus, kaubanduskoja liikmed, koja
juristid, kaubanduskoja Tartu esindus, kaubanduskoja ettepanekud. With the full
name the capitals stay: Eesti Kaubandus-Tööstuskoja peadirektor Mait Palts.

## Headlines

Sentence-style capitals: «Kaubanduskoda esitas valitsusele 15 ettepanekut»,
«Koja hinnangul tuleb vähendada bürokraatiat».

## Editorial standard

First reference «Eesti Kaubandus-Tööstuskoda»; then «kaubanduskoda» or «koda»;
«Kaubanduskoda»/«Koda» at a sentence start; possessive «kaubanduskoja»/«koja».

## The app's own wording

The interface uses «Koda» as an adopted short proper name — the guide's one
allowed capitalised use — in fixed terms such as «Koja arvamus», «Koja algatus»
and «Lisa Kojale». Those terms are feature names and stay as they are.
